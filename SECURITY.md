# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems in Penvire.

Report them privately instead:

- through GitHub: **Security → Report a vulnerability** in the affected repository, or
- by email to [security@penvire.com](mailto:security@penvire.com).

Please include:

- the affected repository and commit or version,
- what an attacker can do and under which conditions,
- steps or a proof of concept to reproduce it.

You will get a reply as soon as possible. Once the issue is fixed, you will be credited in the advisory unless you prefer otherwise.

## Supported versions

Penvire is in early development and has no releases yet. Only the `main` branch of each repository is supported.

## Penvire Lab

The `penvire-lab-*` repositories are a learning project that never runs in production and holds no real data. Findings there are welcome and may be reported as regular public issues. Attacking the lab is part of the project, and every write-up helps.

If a lab finding also affects the product, report it privately as described above.
